How it works

Three layers, all inspectable. The club's own policy file decides what the agent may do alone.

🌙

1 · The night run

Every mail is triaged (intent, facts, confidence). Sign-ups, address changes and questions are processed automatically — register updated, warm replies drafted to the outbox. Spam is discarded.

⚖️

2 · Only real decisions reach you

Fee waivers. Mid-season cancellations. Complaints. Each becomes a decision card: the mail, what the agent understood, its proposal — and the exact policy line that escalated it.

🛡️

3 · Policy is data

A 30-line YAML file the club edits. It drives routing, tool approvals and escalations. Medical mentions always stop for a human — guaranteed by code, not by model mood.
